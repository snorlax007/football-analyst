## Implementation Notes

- `lib/inngest.ts` — Inngest client + `generateAnalysis` function; triggers on `analysis/requested` event; 2 retries; sends push notification on completion via `sendPushToUser`
- `app/api/inngest/route.ts` — dynamic serve: loads Inngest handlers only when `INNGEST_SIGNING_KEY` (prod) or `INNGEST_DEV=1` (dev) is set; returns 200 info message when unconfigured
- `app/api/analysis/[matchId]/route.ts` — if Inngest configured: sends event, returns `{status: "queued"}` immediately and returns early; if not configured: falls back to synchronous inline execution
- `app/matches/[id]/MatchClient.tsx` — new `queued` state shows amber pulsing indicator + message; polls `GET /api/matches/{id}` every 3s until analysis appears; stops polling after 2 minutes; "Generate" button disabled while queued
- **To enable in dev:** set `INNGEST_DEV=1` and run `npx inngest-cli@latest dev`
- **To enable in prod:** set `INNGEST_EVENT_KEY` and `INNGEST_SIGNING_KEY` in Vercel env vars
