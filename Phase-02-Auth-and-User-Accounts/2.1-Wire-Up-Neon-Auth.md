## Implementation Notes

- Used `jose` for edge-compatible JWT (HS256, 7-day expiry, httpOnly cookie `fa_token`)
- bcryptjs v3 uses named ESM exports: `import { hash, compare } from "bcryptjs"`
- In Next.js 16, middleware file is `proxy.ts` (not `middleware.ts`) — same API, renamed
- `lib/auth.ts`: `signToken()`, `verifyToken()`, `getSession()` helpers
- `cookies()` is async in Next.js 16 — must `await cookies()`
- DB tables added: `users` (id TEXT PK, name, email UNIQUE, password_hash, image, created_at)
