## Implementation Notes

- `user_usage` table: SERIAL PK, `user_id TEXT REFERENCES users(id) ON DELETE CASCADE`, `month TEXT`, `reports_generated INT DEFAULT 0`
- `UNIQUE(user_id, month)` enables atomic upsert: `INSERT ... ON CONFLICT DO UPDATE SET reports_generated = reports_generated + 1`
- `/api/user/usage` GET — returns `{ used, limit: 5, remaining }`
- Analysis route (`/api/analysis/[matchId]`): checks auth → checks usage → runs Claude → increments count
- Returns `remaining` in analysis response so client can update UI immediately
- `FREE_LIMIT = 5` exported from `lib/auth.ts` — single source of truth
