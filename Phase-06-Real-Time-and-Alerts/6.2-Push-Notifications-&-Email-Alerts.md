## Implementation Notes

- `lib/push.ts`: `sendPushToUser()` and `sendPushToTeamFollowers()` using `web-push` package + VAPID keys. Removes stale subscriptions on HTTP 410.
- `lib/email.ts`: `sendPostMatchEmail()` and `sendWeeklyDigest()` via Resend. No-ops if `RESEND_API_KEY` not set.
- DB table: `push_subscriptions(user_id, endpoint, p256dh, auth)` with `ON CONFLICT DO UPDATE`.
- `app/api/push/subscribe/route.ts` — GET (VAPID public key), POST (subscribe), DELETE (unsubscribe).
- `components/PushSubscribeButton.tsx` — browser support check, subscribe/unsubscribe toggle, `urlBase64ToUint8Array` helper, `applicationServerKey` cast to `ArrayBuffer`.
- `public/sw.js` service worker handles `push` and `notificationclick` events.
- `components/ServiceWorkerRegistrar.tsx` registered in `app/layout.tsx`.
- Push subscribe button added to dashboard header alongside user greeting.
