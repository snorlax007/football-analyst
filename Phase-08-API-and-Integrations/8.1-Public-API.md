## Implementation Notes

- `lib/apiAuth.ts` — key format `faa_` + 32 hex chars; SHA256 hash stored in DB; raw key shown once on creation
- `app/api/keys/route.ts` — GET list + POST create (Pro+ gated, max 5 keys)
- `app/api/keys/[keyId]/route.ts` — DELETE revoke
- `app/api/v1/match/[id]/analysis/route.ts` — Bearer auth, full match data + top players
- `app/api/v1/player/[id]/stats/route.ts` — player career stats + FPL score estimate
- `app/settings/api-keys/page.tsx` — UI with copy-once reveal, usage bar, revoke button
- `app/docs/page.tsx` — full API docs (auth, rate limits, endpoints, widget embed, webhooks, errors)
- Rate limiting: `api_usage(api_key_id, day, count)` table; Pro=100 req/day, Team=1000 req/day
- `organizations.id` is UUID (TEXT), not INT — FK must use TEXT
