## Implementation Notes

- `lib/webhooks.ts` — HMAC-SHA256 signing (`X-FA-Signature: sha256=...`), fire-and-forget with `AbortSignal.timeout(10000)`
- Events: `match.analysis.completed`, `match.live.event`, `pre_match.report.generated`
- `app/api/webhooks/config/route.ts` — GET list + POST create (Team+ gated, HTTPS required, max 3 webhooks)
- `app/api/webhooks/config/[id]/route.ts` — DELETE deactivate
- `app/settings/webhooks/page.tsx` — UI with event checkboxes, secret reveal
- Webhook fired in `app/api/analysis/[matchId]/route.ts` after analysis saved (for org members)
- `webhooks.org_id` is TEXT (UUID FK to `organizations.id`)
