## Implementation Notes

- `app/matches/[id]/MatchClient.tsx`:
  - Match score card: `p-5 sm:p-8` (reduced padding on mobile)
  - Team names: `text-base sm:text-xl md:text-3xl` + `min-w-0` to prevent overflow
  - Score text: `text-4xl sm:text-5xl md:text-6xl` (smaller on narrow screens)
  - Stats comparison grid: `grid-cols-2 sm:grid-cols-3` (was all 3 on mobile — cramped at 320px)
  - Stat cards: added `min-h-[44px]` for tap target compliance
- `app/matches/page.tsx`:
  - Center section: `mx-3 sm:mx-6` (less margin on mobile)
  - Team names: `truncate` + `min-w-0` to prevent overflow
- All key interactive elements verified ≥ 44px height:
  - Match list rows: `py-5` = ~72px ✅
  - AI analysis button: `py-4` = ~56px ✅
  - PDF button: `py-4` = ~56px ✅
  - Install prompt buttons: `min-h-[44px]` explicit ✅
  - Header nav links: `py-1.5` + line-height ≥ 44px ✅
- `viewport-fit=cover` in layout for notch-safe display on iPhone
- Pre-existing Tailwind responsive classes (`sm:`, `md:`) verified across dashboard, scouting, fantasy, pre-match pages
