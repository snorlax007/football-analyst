## Implementation Notes

- `public/manifest.json` — name, short_name, display: standalone, theme_color: #10b981, SVG icon, shortcuts to /matches and /fantasy
- `public/icon.svg` — custom SVG football AI icon (dark background, emerald circle/lines)
- `public/offline.html` — fallback page served when offline with no cached content
- `public/sw.js` — updated with three-layer caching strategy:
  - `/_next/static/` → cache-first (content-hashed filenames)
  - `/matches/` and `/share/` → network-first, cache for offline reading
  - All other pages → network-first with offline.html fallback
  - API routes (`/api/`) → bypass SW completely (always fresh)
- `components/InstallPrompt.tsx` — listens for `beforeinstallprompt`; slide-up banner with Install/Not now; persists dismissal to localStorage; hidden in standalone mode
- Push notifications built in Phase 6: `PushSubscribeButton`, `public/sw.js` push/notificationclick handlers, `/api/push/subscribe`
- `app/layout.tsx` — manifest link, theme-color meta, apple-touch-icon, viewport-fit=cover
